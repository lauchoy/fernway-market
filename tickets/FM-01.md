TICKET: FM-01  Repo scaffold, compose, CI skeleton, Makefile

GOAL: `make up` starts the stack and `/healthz` returns 200; CI runs lint and an empty test suite green.

FROZEN AUTHORITIES: SPEC sections 13 (stack, layering, repo layout), 15 (static gate), 16 (public repo hygiene), 17 (FM-01 row), 20 (decisions).

IN SCOPE:
- `api/` skeleton: `pyproject.toml` (Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2.0, Alembic, pytest, ruff, mypy, import-linter), package `fernway/{routes,services,domain,repositories,jobs,ai,config}/`, a `/healthz` route only, `tests/{unit,property,integration,golden,contract}/` with one trivial passing test
- import-linter contract: `fernway.domain` imports nothing from FastAPI or SQLAlchemy
- `web/` placeholder: Vite + TypeScript strict, eslint, `tsc --noEmit`, no UI
- `docker-compose.yml` (api + Postgres 16), `Dockerfile` for the api only, `Makefile` (`up`, `down`, `lint`, `test`), `.env.example`, `.gitignore`, `LICENSE` (MIT)
- `.github/workflows/ci.yml` (lint + test), `docs/DECISIONS.md` seeded with the section 20 decisions and the FM-01..03 planning decisions agreed on 2026-10-01
- `config/` directory with placeholder `.gitkeep` only

OUT OF SCOPE: any schema or migration (FM-02), `/readyz`, web UI, single-image build serving the web app and `render.yaml` (FM-16), deploy workflow, gitleaks and audit steps in CI (FM-16), Sentry, auth, worker.

ACCEPTANCE:
1. Given a clean clone with no secrets, when `make up` runs, then `GET /healthz` returns 200.
2. Given the repo, when `make lint` runs, then ruff, mypy --strict, import-linter, eslint and `tsc --noEmit` all pass.
3. Given the repo, when `make test` runs, then the api and web suites run and pass with the single placeholder test each.
4. Given an import of FastAPI or SQLAlchemy inside `fernway/domain`, when `make lint` runs, then import-linter fails (proven once by a throwaway violation, output pasted in evidence).
5. Given a push to any branch, when the CI workflow runs, then lint and test jobs pass.

EVIDENCE: `make up` plus `curl -i localhost:<port>/healthz` output; `make lint` and `make test` output; the failing import-linter run from acceptance 4; CI run link or local `act` output; `git diff --stat`.

STOP IF: spec conflicts with reality (for example a pinned version is unavailable), a needed value has no source, two attempts fail, or scope must grow.
